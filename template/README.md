## Install

### Spicetify Marketplace

1. Install [Spicetify](https://spicetify.app) and the [Marketplace](https://github.com/spicetify/marketplace).
2. Open Marketplace in Spotify, go to **Themes**, search for **{{NAME}}**, and click **Install**.
3. Pick a color scheme from the Marketplace settings.

### Manual

1. Copy this folder to `%APPDATA%\spicetify\Themes\{{NAME}}` (Windows) or `~/.config/spicetify/Themes/{{NAME}}` (macOS/Linux).
2. Run:

   ```
   spicetify config current_theme {{NAME}} color_scheme <Scheme>
   spicetify apply
   ```
