# SolarizedDark

Ethan Schoonover's Solarized Dark palette for Spotify: base03 backgrounds, base0/base1 text and blue/cyan accents.

![SolarizedDark preview](preview.png)

The palette is [Solarized](https://ethanschoonover.com/solarized/) by Ethan Schoonover.

## Color schemes

- `Dark`: the Solarized Dark palette (base03 background, blue and cyan accents)

## Install

### Spicetify Marketplace

1. Install [Spicetify](https://spicetify.app) and the [Marketplace](https://github.com/spicetify/marketplace).
2. Open Marketplace in Spotify, go to **Themes**, search for **SolarizedDark**, and click **Install**.
3. Pick a color scheme from the Marketplace settings.

### Manual

1. Copy this folder to `%APPDATA%\spicetify\Themes\SolarizedDark` (Windows) or `~/.config/spicetify/Themes/SolarizedDark` (macOS/Linux).
2. Run:

   ```
   spicetify config current_theme SolarizedDark color_scheme <Scheme>
   spicetify apply
   ```
